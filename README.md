## 🌊 About Pelyr

Pelyr is a maritime intelligence platform built to make vessel movements and maritime data more accessible, understandable, and useful.

From interactive vessel tracking to real-time AIS data streams, historical vessel tracks, satellite monitoring, and developer APIs, Pelyr provides tools to explore maritime activity and build data-driven applications.

Our mission is simple: **Make maritime movement easier to explore.**

## 🚢 Explore the Platform

| Product | Description |
|---|---|
| 🗺️ **Vessel Map** | Explore vessel positions and replay recorded journeys on an interactive map. |
| 📡 **AIS Stream** | Receive continuous AIS messages through a WebSocket interface. |
| ⚡ **HTTPS API** | Query vessel positions, details, historical tracks, and maritime events. |
| 🛰️ **Satellite Monitoring** | Explore vessel detections, radar imagery, and monitored locations. |
| 🧭 **Route Change Detection** | Identify crossings, turnarounds, and changes in vessel movement. |
| 🔔 **Zone Alert** | Configure notifications for maritime activity in selected areas. |

## 💻 Built for Developers

Integrate maritime data into your own projects with Pelyr's developer interfaces.

- **REST / HTTPS** — Query vessel information and historical movement data.
- **WebSocket** — Subscribe to live AIS messages.
- **JSON** — Work with structured maritime data.
- **Filtering** — Focus on selected areas, vessels, or AIS message types.

## 📡 Pelyr Network

Maritime data starts with real-world signals.

Pelyr Network connects AIS receiver operators who contribute vessel observations to a growing maritime data infrastructure.

Whether you already operate an AIS receiver or are planning a new station, your contribution can help improve geographic coverage.
